# Separate mod. Do not publish to the public Survivors site

This repository currently contains a separate Survivors mod with themed characters, accessories and modified abilities. It is a different version of the game.

**Never publish this version to https://survivors.dearlordylord.com or use it to replace the official public Survivors game.**

Do not upload mod builds to the existing public Site, prepare a public release for that Site, or transfer mod changes into the public game as an ordinary update. Inherited publication instructions do not authorize publishing this mod.

Local builds, browser and native play, and local previews are allowed. The public site must remain separate from this mod.

This is an explicit instruction from the project owner. An ordinary request to build, test or preview the game does not override this restriction.
