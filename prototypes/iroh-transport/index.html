What this prototype proves

The Bend protocol and real Iroh transport can exchange messages between two browser endpoints. Browsers use Iroh relays; this page does not demonstrate direct NAT traversal or multiplayer gameplay. A locally accepted send is not a delivery acknowledgment: check the other participant's received journal.

No game save is loaded. Endpoint identity and messages live in memory and reset when the page is closed.
