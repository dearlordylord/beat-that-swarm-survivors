## Common methodology

1. Primary sources: official game pages, developer materials, open source. A source about gameplay mechanics does not establish the engine's architecture.
2. Distinguish game appeal, ECS suitability and suitability for the current Bendvy specifically.
3. Evaluate the causal benefit of ECS: independent component combinations and intersecting system queries; relations and lifecycles; events and independent readers; phases and structural barriers; observability and world persistence.
4. Scale alone does not demonstrate ECS benefits. Cellular automata, graph solvers, pathfinding, physics and rendering require their own architecture.
5. Do not claim scale, FPS, speedups or determinism without executable evidence. This study runs no performance campaigns and does not change ECS.
6. For each direction: the strongest version of the hypothesis, counterarguments, a real first playable slice, host dependencies and a criterion for rejecting the recommendation.
7. After initial reports: compare on a common scale, cross-review, verify disputed sources, and make a final choice with alternatives.

## Initial project facts

Read `bendvy/README.md`, `docs/next-core-checkpoint.md`, `docs/agent-workflow.md`, `docs/SPEC.md`, `examples/arena/README.md` and the beginning of the current parity index.

- Bendvy provides ECS, not a complete game engine: renderer, physics, audio and asset pipeline are outside its stated scope.
- Components, queries, resources, events, schedules, deferred commands, relations, states, inspection and snapshots with a limited contract exist. API availability does not establish suitability at the chosen game's scale.
- The browser arena already demonstrates enemies, pickups, bolts, pulses and chains, but stores a composite `Body` and uses direct query orchestration. To demonstrate ECS more deeply, the next game must establish the benefit of independent component composition and multiple systems.
- Quantitative optimization is deferred by the current SPEC; game-selection research does not resume it.
